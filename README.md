# Dock Launcher 1.0

A lightweight Android launcher for tablets: a big widget home screen and a tvOS-style dock.

## Features
- Large widget area with grid snapping: long-press a widget to move or resize it
- tvOS-style dock for favorite apps (icons grow on touch)
- App drawer: swipe up from the bottom to open, swipe down to close
- Search in the app drawer and in the widget picker
- Vertical volume slider on the right
- No dependencies, tiny APK, low RAM usage

## Usage
- Long-press an empty spot on the home screen to add a widget
- Long-press an app in the drawer to add it to the dock
- Long-press a dock icon to remove it

## Install
1. Download docklauncher.apk below
2. Allow installing from unknown sources
3. Open the APK, then press Home and choose Dock Launcher as the default home app
